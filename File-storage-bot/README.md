# File Storage Bot

Telegram-бот для персонального хранения файлов и обмена ими с другими пользователями.

## Возможности

- Сохранение фотографий, видео и документов, отправленных боту.
- Раздельное хранение файлов по Telegram ID пользователя и типу файла.
- Просмотр файлов по категориям и постраничная навигация.
- Просмотр, скачивание и удаление сохранённых файлов.
- Создание команд доступа к общим файлам и получение файлов, которыми поделились другие пользователи.
- Просмотр списков отправленных и полученных файлов.
- Скачивание файлов пользователя ZIP-архивом.
- Главное меню и управление через команды и inline-кнопки Telegram.

## Команды бота

| Команда | Описание |
| --- | --- |
| `/start` | Запустить бота и открыть главное меню |
| `/help` | Показать справку |
| `/menu` | Открыть главное меню |
| `/about` | Информация о боте и статистика |
| `/files` | Показать все свои файлы |
| `/photos` | Показать фотографии |
| `/videos` | Показать видео |
| `/documents` | Показать документы |
| `/share_ID` | Получить доступ к файлу по команде, которой поделились |

## Как пользоваться

1. Откройте бота в Telegram и отправьте `/start`.
2. Чтобы сохранить файл, отправьте боту фотографию, видео или документ обычным сообщением.
3. Откройте нужную категорию через меню или команды `/files`, `/photos`, `/videos`, `/documents`.
4. Для обмена откройте файл и выберите действие «Поделиться файлом». Передайте сформированную команду другому пользователю — он сможет отправить её этому боту.
5. Для получения ZIP-архива используйте соответствующую кнопку в меню.

## Где хранятся файлы и данные

Файлы сохраняются на диске компьютера или сервера, где запущен бот:

```text
File-storage-bot/
├── saved_files/
│   └── users/
│       └── <telegram_user_id>/
│           ├── photos/
│           ├── videos/
│           └── documents/
├── main.py
├── simple_bot.py
├── config.py
├── user_storage.py
├── file_utils.py
├── requirements.txt
└── .env
```

При запуске необходимые каталоги создаются автоматически. Файлы разных пользователей хранятся в отдельных папках.

Служебные данные обмена и пользователей сохраняются в файлах `users_data.json` и `shared_files.json` в рабочем каталоге приложения. Логи записываются в `bot.log` (при запуске через `app.py` также используется `app.log`).

Содержимое `saved_files/`, локальный `.env`, JSON-файлы с данными и логи исключены из Git. В репозитории хранится только файл-заполнитель `.gitkeep` внутри `saved_files/`.

> **Важно:** это локальное файловое хранилище. Для сохранности данных настройте резервное копирование папки `saved_files/` и JSON-файлов. При переносе или перезапуске на другом сервере убедитесь, что используется постоянный диск.

## Установка и запуск

Требуется Python 3.8 или новее и токен Telegram-бота, созданный через [@BotFather](https://t.me/BotFather).

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Lesaght/Telegram-Bots.git
   cd Telegram-Bots/File-storage-bot
   ```

2. (Рекомендуется) создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   Linux/macOS:

   ```bash
   source .venv/bin/activate
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе примера:

   Linux/macOS:

   ```bash
   cp .env.example .env
   ```

   Windows PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

5. Заполните переменные окружения. Их можно задать в окружении процесса или загрузить из `.env` средствами вашей платформы:

   | Переменная | Назначение |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | **Обязательно.** Токен бота от BotFather |
   | `BOT_USERNAME` | Имя бота без символа `@` |
   | `BOT_SPECIAL_PASSWORD` | Пароль для проверки пользователей, если он используется в вашей конфигурации |
   | `BOT_ADMIN_ID` | Telegram ID администратора |

   В текущем коде `.env` сам по себе не загружается: переменные должны быть переданы процессу через окружение или настроены средствами хостинга. Не публикуйте токен и другие секреты.

6. Запустите бота:

   ```bash
   python main.py
   ```

Остановить процесс можно сочетанием `Ctrl+C`.

## Запуск через Gunicorn

В проекте есть `app.py`, который запускает Telegram-бота в отдельном потоке и предоставляет WSGI-приложение для Gunicorn. Команда запуска:

```bash
gunicorn app:app
```

Перед запуском настройте переменные окружения, включая `TELEGRAM_BOT_TOKEN`. Для такого способа размещения используйте хостинг с постоянным диском, если хотите сохранять загруженные файлы и JSON-данные между перезапусками.

## Зависимости

Основные зависимости перечислены в `requirements.txt`:

- [pyTelegramBotAPI](https://pypi.org/project/pyTelegramBotAPI/) — взаимодействие с Telegram Bot API.
- [Flask](https://pypi.org/project/Flask/) и [Gunicorn](https://pypi.org/project/gunicorn/) — компоненты для WSGI-совместимого запуска.

## Безопасность и резервное копирование

- Храните `.env` и токен бота вне публичного репозитория.
- Не добавляйте пользовательские файлы и JSON-файлы с данными в Git.
- Ограничьте доступ к серверу и каталогу `saved_files/`.
- Регулярно создавайте резервные копии `saved_files/`, `users_data.json` и `shared_files.json`.
- Срок действия ссылки на общий файл по умолчанию задаётся параметром `SHARE_LINK_TTL` в `config.py` (24 часа).
