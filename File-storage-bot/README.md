# File Storage Bot

Telegram-бот для хранения и обмена файлами: фотографиями, видео и документами.

## Возможности
- Приём и организация файлов по типам
- Просмотр и скачивание сохранённых файлов
- Обмен файлами по ссылкам
- Проверка доступа пользователя

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Запустите: `python main.py`.

Не добавляйте настоящий `.env`, токены, пароли, пользовательские данные и загруженные файлы в Git.
