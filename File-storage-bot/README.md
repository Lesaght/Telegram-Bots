# File Storage Bot

Telegram-бот для хранения и обмена файлами: фотографиями, видео и документами.

## Возможности
- Приём и организация файлов по типам
- Просмотр и скачивание сохранённых файлов
- Обмен файлами по ссылкам
- Проверка доступа пользователя

## Где хранятся файлы
Все загруженные файлы сохраняются локально в папке `saved_files/`, отдельно для каждого пользователя и по категориям:

- `saved_files/users/<user_id>/photos/`
- `saved_files/users/<user_id>/videos/`
- `saved_files/users/<user_id>/documents/`

При первом запуске бот автоматически создаёт необходимые папки. Содержимое `saved_files/` (кроме `.gitkeep`) исключено из Git, поэтому пользовательские файлы не попадут в репозиторий.

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Запустите: `python main.py`.

Не добавляйте настоящий `.env`, токены, пароли, пользовательские данные и загруженные файлы в Git.
